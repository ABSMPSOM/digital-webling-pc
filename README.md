DigitalWebling Ultra transforms your PC activity into a **live RPG-style progression system**.

Your real-world habits become:
- 🧠 Intelligence points
- ⚡ Reflex boosts
- 🎨 Creativity XP
- 💬 Charisma stats
- 🏆 Productivity Aura

# 🚀 Performance First

DigitalWebling was optimized to feel invisible while running.

- Smart refresh intervals
- Low CPU polling
- Lightweight JSON database
- Threaded autosave system

### Result:
```txt

✔ Minimal RAM usage

✔ Instant app switching detection
```

# ⚡ Installation

## 1️⃣ Clone Repository

```bash

```

---

## 2️⃣ Install Dependencies

```bash

```

Or manually:

```bash
pip install customtkinter psutil pywin32
```

---

## 3️⃣ Run Application

```bash
python main.py
```
